# ThirstyAI

ThirstyAI estimates the water, electricity and CO&#8322; footprint of an AI request — as a range, not a single number, because the underlying measurements come from different system boundaries, regions and methods. Every result names the facts and assumptions behind it, each with a confidence rating.

Currently backed by **144 facts** from **35 sources**.
